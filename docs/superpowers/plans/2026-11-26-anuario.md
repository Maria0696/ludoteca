# Anuario Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un resumen de cada año de juego, en pantallas que se pasan una a una, calculado en vivo y congelado al cerrar el año para compararlo con otros.

**Architecture:** Una función pura (`src/lib/anuario.ts`) calcula el resumen de un año a partir de la `Library`. Los años congelados son `YearWrap` en `Library.wraps`, guardados por el repositorio (tabla `year_wraps` en Supabase, el documento de IndexedDB en local) y en las copias de seguridad. Las rutas `/anuario` y `/anuario/[year]` los enseñan; el estado de la app congela solo el año anterior a partir del 1 de enero.

**Tech Stack:** Next.js 16 (App Router), React 19.3, TypeScript, zod, Supabase, Playwright (e2e y unitarias en `tests/e2e`).

**Spec:** `docs/superpowers/specs/2026-11-26-anuario-design.md`

## Global Constraints

- Interfaz en español; textos exactos del spec donde los fija («Tu 2026», «Cerrar el año», «Guardar este año», «Volver a calcular», «En curso», «Guardado el …», «Sin guardar», «Ya puedes ver tu 2026», «Ver todos los años»).
- Solo cuentan fechas dentro del año (`AAAA-MM-DD` comparadas como texto, sin zonas horarias). Los juegos y copias `demo` no cuentan.
- Lo que no tiene fecha no sale (horas, abandonos, «al 100 %», deseos cumplidos).
- Carátulas en `data:` se guardan como `null` al congelar.
- `YearWrapData.version = 1`.
- Rutas: `/anuario`, `/anuario/[year]`. Migración: `supabase/migrations/0017_anuario.sql`.
- Movimiento: fundido + `translateY(8px)`, 200–250 ms, `var(--ease-out)`; con `prefers-reduced-motion`, solo fundido. Sin contadores que suban.
- TDD: cada prueba nueva se ve fallar antes. Capturas a 1440 y 390. En local, solo los specs afectados.

## Review Focus

1. Un año sin nada (`/anuario/2019`): se ve «No hay nada de 2019 en tu ludoteca», sin romperse ni ofrecer congelarlo. → Tarea 4.
2. Un juego terminado dos veces el mismo año cuenta como un terminado y una vuelta. → Tarea 1.
3. Fechas en el borde (`2025-12-31` y `2026-01-01`) caen cada una en su año. → Tarea 1.
4. Un año congelado cuyo juego se borró después sigue enseñando su título (sin carátula si era `data:`). → Tarea 3.
5. Abrir la app varias veces en enero no congela el año dos veces (uno por año). → Tarea 2.

### Task 1: El cálculo del año

**Files:**
- Create: `src/lib/anuario.ts`
- Test: `tests/e2e/anuario.spec.ts`

**Interfaces:**
- Produces:
  - `type WrapGame = { id: string; title: string; coverUrl: string | null; rating: number | null; date: string | null }`
  - `type YearWrapData = { version: 1; year: number; finished: { games: number; replays: number }; started: number; byMonth: number[] /* 12 */; bestMonth: number | null /* 0–11 */; first: WrapGame | null; last: WrapGame | null; favorites: WrapGame[] /* ≤3, con nota */; finishedCovers: WrapGame[] /* ≤8, por fecha */; profile: { genres: string[] /* ≤3 */; family: string | null; moods: Mood[] /* ≤2 */; line: string | null }; library: { copies: number; newGames: number; spent: number; gifts: number; free: number; undatedCopies: number } }`
  - `computeYear(library: Library, year: number): YearWrapData`
  - `hasActivity(data: YearWrapData): boolean` — algún terminado, empezado o copia.
  - `activeYears(library: Library): number[]` — años con actividad, de más nuevo a más viejo.
  - `compareLine(now: number, before: number | undefined, yearBefore: number): string | null` — «+4 que en 2025», «−2 que en 2025», «Igual que en 2025»; `null` sin año anterior o si `before` es 0 y `now` es 0.
  - `profileLine(genre: string | undefined): string | null` — tabla fija género → frase; por defecto «Tu año fue de {género en minúscula}».

- [ ] **Step 1: Escribir las pruebas** en `tests/e2e/anuario.spec.ts` (unitarias, sin página), con juegos de `createGame`:
  - `computeYear` cuenta terminados por juego y vueltas aparte: un juego con `pastRuns: [{ start: "2026-01-02", end: "2026-02-01" }]` y `finishedAt: "2026-06-01"` → `finished: { games: 1, replays: 1 }`.
  - Borde: `finishedAt: "2025-12-31"` cuenta en 2025 y no en 2026; `"2026-01-01"` en 2026.
  - `byMonth[5] === 1` para junio; `bestMonth` el de más; `null` sin terminados.
  - `favorites`: solo terminados en el año con `rating`, de mayor a menor, máximo 3; vacío si ninguno tiene nota.
  - `first`/`last` por fecha de fin dentro del año.
  - `library`: copias con `acquiredAt` en el año; `newGames` cuenta juegos cuya primera copia (por `acquiredAt`) es del año; `spent` suma `pricePaid` de las `priceKind` pagadas o sin tipo; `gifts`/`free` por `priceKind` «regalo»/«gratis»; `undatedCopies` = copias sin `acquiredAt` (todas, no solo del año).
  - Lo `demo` no cuenta.
  - Una carátula `data:image/png;base64,…` sale como `coverUrl: null`.
  - `activeYears` devuelve `[2026, 2025]` con actividad solo en esos años.
  - `compareLine(16, 10, 2025) === "+6 que en 2025"`, `compareLine(8, 10, 2025) === "−2 que en 2025"`, `compareLine(3, 3, 2025) === "Igual que en 2025"`, `compareLine(5, undefined, 2025) === null`.

- Modify: `src/lib/store.tsx` (acciones y congelado automático)
- Test: `tests/e2e/anuario.spec.ts`

**Interfaces:**
- Consumes: `computeYear`, `hasActivity` (Tarea 1).
- Produces:
  - `type YearWrap = { id: string; year: number; data: YearWrapData; frozenAt: string; createdAt: string; updatedAt: string }`
  - Acción `freezeYear(year: number): YearWrap` — calcula y guarda (si ya existe ese año, lo sustituye manteniendo su `id`).
  - Acción `deleteWrap` no hace falta (YAGNI).
  - Congelado automático: al pasar el estado a `ready`, si `hoy >= {año}-01-01`, el año anterior no está en `wraps` y `hasActivity(computeYear(lib, año anterior))`, se llama a `freezeYear(año anterior)` una sola vez.

Migración:

```sql
create table if not exists public.year_wraps (
  id uuid primary key,
  owner_id uuid not null default auth.uid() references auth.users (id) on delete cascade,
  year integer not null check (year between 1970 and 2200),
  data jsonb not null,
  frozen_at timestamptz not null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  unique (owner_id, year)
);
-- + RLS «solo la propietaria», índice por owner_id y grants: igual que saga_extras (0012).
```
